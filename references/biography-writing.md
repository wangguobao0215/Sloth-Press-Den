# 人物传记写作方法论

> 基于《哈萨比斯：谷歌AI之脑》实战生成
> 验证日期：2026-06-23

---

## 核心原则

1. **所有事实性陈述必须有来源** — 不能编造内心活动、未经报道的对话、无据可查的心理描写
2. **来源优先于叙事** — 如果找不到可靠来源，宁可跳过那段不写，不要"填补空白"
3. **标注格式** — 每章末尾列出引用来源：`[1] 来源描述 (URL/出版物)`，正文中以编号标注 `[1]`

## 素材来源优先级

| 优先级 | 来源类型 | 例子 |
|--------|---------|------|
| P0 | 官方传记/维基百科 | Wikipedia API (action=parse&page=Title) |
| P1 | 学术论文/自传性演讲 | arXiv, Google Scholar, TED演讲 |
| P2 | 权威媒体报道 | Nature/Science/Wired/Guardian |
| P3 | 长篇采访 | Lex Fridman Podcast, 60 Minutes |
| P4 | 纪录片 | 如DeepMind AlphaGo纪录片 |
| ⚠️ 不可用 | 无来源的AI生成内容、猜测性描述 |

## 章节结构模板

传记类书不建议用四篇制（技术书的套路），建议**两幕或三幕制**，以人物生命阶段为组织线索：

```
第一幕：形成（童年→教育→早期事业）
  第1章 早年 — 家庭背景、关键童年经历
  第2章 初试 — 早期职业、第一次创业

第二幕：探索（学术→创业→首次突破）
  第3章 学术转型 — 从商业到学术的转折
  第4章 创立 — 核心人物的关键合作

第三幕：影响（巅峰→融合→愿景）
  第5章 里程碑 — 重大突破
  第6章 遗产 — 对领域的长远影响
```

- 每章控制在3500-5000字
- 每章以**场景或事件**开头（避免"xxx年x月，某人做了某事"的编年体）
- 以引用来源收尾

## 叙事纪律

- ❌ 不要写"他想到了""他感到""他坚信"——除非来自采访原文且有来源
- ❌ 不要写"如果他当时……的字眼"（主观臆测）
- ✅ 写"据报道""他在采访中说""根据X的回忆"
- ✅ 可以用公开的演讲、论文、采访原文中的直接引语
- ✅ 可以用纪录片或影像资料中的画面描述（标记来源）
- ✅ 可以用时间线梳理（几月几日发生了什么）
